# Generador de Órdenes de Acción Táctica (OAT)

## 📋 Descripción

Sistema web para la generación automatizada de Órdenes de Acción Táctica (OAT) del GT ÁGUILA (GOMAI) en Ecuador.

## 🚀 Características

- **Carga de Excel**: Importa datos desde archivos Excel
- **Selección de oficiales**: Elige comandante y oficial A3
- **Generación automática**: Crea documentos OAT con formato militar
- **Paginación inteligente**: Distribuye contenido en páginas A4
- **Formato profesional**: Márgenes, tipografía, sellos "SECRETO"
