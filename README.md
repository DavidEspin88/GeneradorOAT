# Generador de Órdenes de Acción Táctica (OAT)

## 📋 Descripción

Sistema web para la generación automatizada de Órdenes.

## 🚀 Características

- **Carga de Excel**: Importa datos desde archivos Excel
- **Selección de oficiales**: Elige comandante y A3
- **Generación automática**: Crea documentos OAT
- **Paginación inteligente**: Distribuye contenido en páginas A4
- **Formato profesional**: Márgenes, tipografía
